Este artigo explica como criar uma lista de desejos no Admin. A tarefa consiste em abrir a página de listas de desejos, criar uma nova lista com um nome e salvá-la.

## Passo a passo

Siga as instruções a seguir para criar uma lista de desejos:

1. Acesse a página **Wishlists** no Admin.
2. Selecione `New wishlist`.
3. Informe o nome da lista no campo **Name** (por exemplo, `Winter`).
4. Selecione `Save`.

A lista criada passa a aparecer listada na página **Wishlists**.
