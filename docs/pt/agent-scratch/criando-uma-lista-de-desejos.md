Você pode criar uma lista de desejos na tela **Wishlists** do Admin, nomeando a lista e salvando-a.

## Passo a passo

Siga as instruções a seguir para criar uma lista de desejos:

1. Acesse a tela **Wishlists** no Admin.
2. Selecione **New wishlist**.
3. No campo **Name**, informe o nome da lista, por exemplo `Winter`.
4. Clique em **Save**.

A lista criada passa a aparecer na tela **Wishlists**.
