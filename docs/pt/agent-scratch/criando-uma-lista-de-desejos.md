Este artigo explica como criar uma lista de desejos na página **Wishlists** do Admin. Uma lista de desejos agrupa produtos sob um nome, como `Winter`, para facilitar sua organização e consulta posterior. Para criar uma lista de desejos pela API, consulte [Creating a wishlist](https://developers.vtex.com/docs/guides/creating-a-wishlist).

## Passo a passo

Siga as instruções a seguir para criar uma lista de desejos:

1. No Admin, acesse a página **Wishlists**.
2. Selecione `New wishlist`.
3. No campo **Name**, informe o nome da lista (exemplo: `Winter`).
4. Selecione `Save`.

Agora a lista criada aparece na página **Wishlists**, com o nome informado.
