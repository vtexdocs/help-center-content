Um fluxo é uma sequência de ações e decisões que automatiza interações com contatos. Ao criar um fluxo, você define o nome, as palavras-chave opcionais do trigger e o tipo.

Você adiciona as etapas depois de criar o fluxo. Para saber como um fluxo é estruturado, consulte [Fluxo de automação](https://help.vtex.com/pt/docs/tutorials/visao-geral-fluxo-de-automacao).

## Antes de começar

Apenas usuários com permissão de administrador, moderador ou colaborador podem criar fluxos.

## Criar um fluxo

Para criar um fluxo, siga estas etapas.

> ⚠️ Se o Agent Builder estiver ativo, as palavras-chave e outros triggers não iniciam o fluxo. Nesse caso, o Agent Builder inicia os fluxos.

1. Acesse sua organização no dashboard do [VTEX CX Platform](https://dash.weni.ai/orgs).
2. No menu lateral, clique em **Fluxo de automação**.
3. Clique em `Criar fluxo`.
4. Em **Nome**, insira um nome para o fluxo. O campo **Nome** é obrigatório e pode ser alterado depois.
5. (Opcional) Em **Palavras-chave dos Triggers globais**, insira as palavras-chave que iniciam o fluxo quando um contato as envia. Você pode deixar esse campo vazio e adicionar triggers depois. Para mais informações, consulte [Criar um trigger](https://help.vtex.com/pt/docs/tutorials/como-criar-um-disparador) e [Tipos de Trigger](https://help.vtex.com/pt/docs/tutorials/tipos-de-gatilho).
6. Em **Tipo**, selecione **Mensagem**, **Chamada Telefônica** ou **Pesquisador**. O campo **Tipo** é obrigatório, e a opção **Mensagem** é selecionada por padrão. Consulte [Tipos de fluxo](#tipos-de-fluxo).
7. Clique em `Criar`.

O fluxo é criado, e você pode adicionar ações e decisões no editor. Para mais informações, consulte [Editor de fluxo e suas ferramentas](https://help.vtex.com/pt/docs/tutorials/editor-de-fluxo-e-suas-ferramentas).

## Tipos de fluxo

O tipo determina como o fluxo interage com os contatos. As opções são **Mensagem**, **Chamada Telefônica** e **Pesquisador**.

A opção **Mensagem** é selecionada por padrão. Use-a para canais de texto, como WhatsApp, Facebook Messenger e SMS.

Use **Chamada Telefônica** para canais de ligação. Esse tipo inclui cartas de ação e decisão específicas para chamadas.

Use **Pesquisador** em fluxos que coletam respostas de pesquisas.
