O Desk Copilot ajuda atendentes humanos no [Live Desk](https://help.vtex.com/pt/docs/tutorials/visao-geral-do-live-desk) a responder a clientes com mais agilidade. Ele lê a conversa ativa, reage a cada mensagem do cliente e sugere a próxima melhor ação. O atendente humano continua no controle: ele decide se copia, edita ou envia cada sugestão.

## Como o Desk Copilot funciona

O Desk Copilot funciona como um projeto separado, dentro da mesma organização do seu projeto de atendimento. Esse projeto tem:

- Um **Manager** próprio, já configurado para apoiar atendentes humanos.
- Uma **base de conhecimento interna**, para informações confidenciais que só devem aparecer para a equipe.
- Os mesmos **agentes de comércio oficiais** usados pelos agentes de IA.

Você também pode estender o Desk Copilot com agentes personalizados. Para saber como ativar e configurar o copiloto, consulte [Usando o Desk Copilot para apoiar atendentes no Live Desk](https://help.vtex.com/pt/docs/tutorials/usando-o-desk-copilot-para-apoiar-atendentes-no-live-desk).

## Tipos de sugestão

A cada mensagem do cliente, o Desk Copilot pode propor uma das seguintes ações:

- **Resposta pronta para envio**, no tom adequado ao atendimento.
- **Busca conversacional de produtos**, com carrosséis de produtos.
- **Carrinho montado** com os itens da conversa.
- **Consulta de pedido.**
- **Link de pagamento.**

Para saber como usar e avaliar as sugestões no Live Desk, consulte [Usando o Desk Copilot para apoiar atendentes no Live Desk](https://help.vtex.com/pt/docs/tutorials/usando-o-desk-copilot-para-apoiar-atendentes-no-live-desk).

## Contexto usado nas sugestões

Além do texto da conversa, o Desk Copilot usa como contexto:

- **Áudios transcritos** enviados pelo cliente.
- **Arquivos compartilhados** na conversa, como PDFs.

## Como ativar o Desk Copilot

O Desk Copilot está disponível para todos os clientes, em todas as regiões. Para ativá-lo, siga o passo a passo a seguir:

1. No projeto desejado do VTEX CX Platform, clique em **Configurações > Live Desk**.
2. Selecione a aba **Desk Copilot**.
3. Clique em `Criar projeto Copilot`.
4. Defina o nome do projeto.

> ⚠️ O menu pop-up sugere um nome idêntico ao nome do projeto. Para evitar confusão, sugerimos que você escolha um nome diferente ou adicione **Copilot** ao nome do projeto (exemplo: **Projeto X Copilot**).

5. Clique em `Criar`.

Após fazer a ativação do Desk Copilot, você será redirecionado à página de **Analytics** do projeto do copiloto.

## Cobrança

Cada conversa assistida pelo Desk Copilot é uma conversa faturável comum. Não é necessário alterar o contrato para usar o recurso.
