O [Payment Card Industry Security Standards Council (PCI SSC)](https://www.pcisecuritystandards.org/) é um fórum global aberto que desenvolve, aprimora, armazena, divulga e implementa padrões de segurança para a proteção de dados. O conselho foi fundado pelas empresas American Express, Discover Financial Services, JCB International, Mastercard e Visa Inc.

Entre os padrões mantidos pelo PCI SSC está o [PCI DSS (Payment Card Industry Data Security Standard)](https://www.pcisecuritystandards.org/standards/pci-dss/), que define os requisitos de segurança para empresas que processam, armazenam ou transmitem dados de cartões de crédito e débito. A VTEX é certificada no PCI DSS como provedora de serviços, o que significa que os dados de cartão digitados pelos clientes no ambiente da VTEX são tratados em uma infraestrutura certificada, sem que a loja precise de uma certificação PCI própria para vender nesse ambiente. A exceção são os apps mobile nativos, que enviam os dados de pagamento à VTEX a partir de um ambiente externo, como explica o artigo [É necessário ter certificado PCI para vender em apps mobile nativos?](/pt/docs/tutorials/e-necessario-ter-certificado-pci-para-vender-em-apps-mobile-nativos).

O certificado PCI DSS da VTEX está disponível no [VTEX Trust Center](https://compliance.vtex.com/?itemUid=53e1508c-665e-45a8-9ce0-03fdf9ae1efb&source=title).
