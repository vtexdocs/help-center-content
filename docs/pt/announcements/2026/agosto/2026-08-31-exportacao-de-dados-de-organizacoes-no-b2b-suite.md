A partir de 31 de agosto de 2026, todas as lojas que usam o [B2B Suite](/pt/docs/tutorials/b2b-suite-visao-geral), em todas as regiões, podem exportar em planilhas os dados de organizações compradoras, centros de custo, endereços e usuários cadastrados na loja. A funcionalidade está em disponibilidade geral e permite auditar essas configurações em massa.

## O que mudou?

O aplicativo **Organizações B2B** passa a oferecer a opção `Exportar` no botão `Novo` da aba **Organizações**. Ao iniciar uma exportação, você escolhe quais tipos de dados deseja baixar:

- Organizações
- Centros de custo
- Endereços
- Usuários

Os dados são exportados em formato XLSX. Cada tipo de dado selecionado é processado separadamente e tem sua própria ação `Baixar arquivo` na janela de exportação.

Não há limite de registros por exportação. O tempo de geração dos arquivos depende do volume de dados exportados.

A exportação permite apenas baixar os dados. Não é possível editar dados em massa a partir dos arquivos exportados.

## Por que fizemos essa mudança?

Revisar as configurações de cada organização individualmente no Admin VTEX não é viável em contas com muitas organizações compradoras. Com a exportação, a auditoria desses dados em massa se torna prática.

## O que precisa ser feito?

1. Atualize o aplicativo Organizações B2B para a versão mais recente.
2. Verifique se os usuários que vão realizar a exportação têm permissão de acesso à aba Organizações. Saiba mais em [Gerenciamento de permissões no B2B Suite](/pt/docs/tutorials/gerenciamento-de-permissoes-no-b2b-suite).

Para saber como exportar os dados, consulte o artigo [Exportando dados de organizações](/pt/docs/tutorials/exportando-dados-de-organizacoes).
