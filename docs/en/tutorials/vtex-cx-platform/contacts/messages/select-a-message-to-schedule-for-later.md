Scheduled messages let you send a message to contacts or groups at a date and time you choose. You can also set a scheduled message to repeat daily, weekly, or monthly.

To schedule a message, follow these steps:

1. In your project, click **Studio** in the left side menu, then click **Messages**.
2. Click `Send Message`.
3. Select one or more contacts or groups.
4. Enter the message you want to send.
5. Select **Schedule for later**.
6. Click `Send`.

After you click `Send`, the message is listed in the **Schedules** folder. Go to this folder to view or edit the message before it's sent.
