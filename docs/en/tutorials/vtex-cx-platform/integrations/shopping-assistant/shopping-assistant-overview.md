**Shopping Assistant** is the VTEX CX Platform web chat channel. You use it to assist customers with an artificial intelligence (AI) agent. Customers can ask questions and find products without leaving your website.

The chat runs in a widget. You install the widget with a script generated by VTEX CX Platform, and you set its appearance and behavior in the channel settings.

## What customers see

After you install the script, the widget is available on the configured store pages. Customers open the chat and talk to the AI agent on the website.

On product pages, the chat can show up to three suggested questions. The questions are based on published product information, such as the name, description, brand, and technical specifications. When a customer selects a question, the chat opens and sends that message. Question quality depends on how complete that product information is. To learn how the questions are generated and how to enable or disable them, see [Shopping Assistant: Suggested questions](https://help.vtex.com/en/docs/tutorials/shopping-assistant-suggested-questions).

When the agent shows recommended or catalog products in the conversation, each product card displays `-`, the quantity, and `+`. The customer sets a quantity, and that quantity is added to the cart.

> ℹ️ The quantity control is included in Shopping Assistant for stores using FastStore and Store Framework.

## Appearance and preferences

The **Appearance** and **Preferences** tabs control the widget. The **Script Code** tab provides the script you install on the website.

In **Appearance**, you can set the widget title, messages, color, avatar, and styles.

In **Preferences**, you can set options such as the following:

- Show the chat as a floating window or embed it in the page.
- Let customers expand the chat to full screen.
- Show suggested questions on product pages.
- Let customers send voice messages and images.
- Keep conversation history between sessions.
- Restart a conversation after a period of inactivity.
- Let the agent open another page when it sends a link.
- Add products the agent suggests to the store's native cart.

> ℹ️ Opening another page from a link and adding products to the store's native cart are in beta and may change.

The options you enable in **Preferences** determine how the chat behaves. For the full list of fields and the installation steps, see [Configuring the Shopping Assistant](https://help.vtex.com/en/docs/tutorials/configure-shopping-assistant).
