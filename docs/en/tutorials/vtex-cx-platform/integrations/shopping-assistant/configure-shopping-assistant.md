Shopping Assistant is the VTEX CX Platform web chat channel that allows you to assist website visitors with an AI agent. You customize the widget's appearance and behavior, then install the chat on your website using a script generated by the platform.

This tutorial explains how to access the channel, customize its appearance, configure its preferences, and install the script on your website.

## Installing the app

To install the app in your store, follow these steps:

1. In the desired project, go to **Settings > Channels**.
2. Click the **Discovery** tab.
3. Enter **Shopping Assistant** in the search field or find the app card.
4. Click the <i class="fas fa-plus" aria-hidden="true"></i> button to add the app to your project.

## Accessing the app

To open the Shopping Assistant settings, follow these steps:

1. In the project, go to **Settings > Channels**.
2. Click the **My apps** tab.
3. Under **Installed apps**, click the **Shopping Assistant** card you want to configure.

When you click the card, the **Shopping Assistant** settings window opens with the **Appearance**, **Preferences**, and **Script Code** tabs. A widget preview displays the results of your changes.

## Customizing the app

You can customize your project's Shopping Assistant by changing the agent's appearance and features.

### Appearance

The **Appearance** tab defines the chat widget's appearance. You can configure the following fields:

- **Chat title:** Name displayed in the widget header.
  - By clicking <i class="fas fa-plus" aria-hidden="true"></i> `More`, you can add optional fields:
    - **Chat subtitle:** Text displayed below the title.
    - **Chat notification message:** Message displayed in the chatbot notification.
    - **Placeholder text:** Placeholder in the message field.
- **Main color:** Chat's main color.
- **Avatar image:** Agent's avatar in the chat.
- **Custom CSS:** Upload a CSS file to apply custom styles to the widget.

### Preferences

The **Preferences** tab defines the chat's behavior. You can configure the following fields:

| Section | Feature | Description |
| --- | --- | --- |
| **Behavior** | Embedded mode | Activate this option to embed the chat in the store page. If you prefer the chat as a floating window, deactivate it. |
| **Behavior** | Show full-screen button | Displays a button that allows users to expand the chat to full screen. |
| **Behavior** | Start chat in full screen | Opens the chat directly in full screen when the user starts a conversation. |
| **Behavior** | Unread message indicator | Displays a visual indicator when the user has unread messages. |
| **Behavior** | Use connection optimization | Activate this option to connect the chat to the Socket only when the user opens the chat or when the user's last message was sent less than 24 hours ago (automatic Socket initialization time). If you prefer the chat to connect to the Socket automatically, deactivate it. |
| **Retail** | Questions suggested by AI (New) | Displays quick-interaction buttons on the product page. AI analyzes the SKU to automatically suggest the most relevant customer questions. |
| **Retail** | Allow Shopping Assistant to automatically redirect the page **(Beta)** | Allows Shopping Assistant to automatically redirect the user to another page when a link is sent during the conversation. This feature is currently in beta and may change. |
| **Retail** | Add to store cart **(Beta)** | Allows users to add products suggested by AI directly to the store's native cart instead of using a cart managed by Shopping Assistant. Recommended for stores with custom carts or checkout flows. This feature is currently in beta and may change. |
| **Media** | Show voice recording button | Displays a button that allows users to send voice messages in the chat. |
| **Media** | Show camera button | Displays a button that allows users to send images in the chat. |
| **Chat history and inactivity** | Keep message history | Preserves conversation history between user sessions. |
| **Chat history and inactivity** | Restart conversation due to contact inactivity | Automatically restarts the conversation after a period of user inactivity. When enabled, you can define this inactivity period in the following field using the HH:mm format. |
| **Chat history and inactivity** | Time between messages | Defines the interval between messages sent by the agent. |

### Script Code

The **Script Code** tab generates the code for installing Shopping Assistant on your website. To install the chat, follow these steps:

1. After configuring Shopping Assistant, click `Save changes`. This generates the script code with your saved preferences.
2. Click the **Script Code** tab.
3. Copy the displayed code or click `Download script`.
4. In your website's code, paste the script above the last `</body>` tag.
