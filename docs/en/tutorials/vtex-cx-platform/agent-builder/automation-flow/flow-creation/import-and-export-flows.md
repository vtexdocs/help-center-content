You can export flows from one organization and import them into another. The export generates a `.json` file, and the import uses that file to add the flows to the destination organization.

A flow is the set of steps a contact follows in a conversation. For how a flow is structured, see [Automation flow](https://help.vtex.com/en/docs/tutorials/automation-flow-overview).

To duplicate a flow inside the same organization, use `Copy` in the flow editor settings menu. Use export when the destination is another organization.

## Exporting flows

You can open the export page from the flow editor or from the organization's general settings. The page lists every flow and campaign in the organization, grouped by usage.

> ⚠️ Flows in the same group interact with each other. If you export only one flow from a group, that flow may not work correctly after you import it. Select every flow in the group.

### Opening the export page from the flow editor

In the flow editor, the settings menu is next to the Start Flow button. `Export Definition` in that menu opens the export page. `Export Translation` is a different option: it exports the flow's language translation, not the flow definition. For the other options in this menu, see [Flow editor and tools](https://help.vtex.com/en/docs/tutorials/flow-editor-and-tools).

To open the export page from the flow editor, follow these steps:

1. In the side menu, click **Flows**.
2. Open the flow you want to export.
3. Open the settings menu next to the Start Flow button.
4. Click `Export Definition`.

The export page opens.

### Opening the export page from the organization's general settings

To open the export page from the organization's general settings, follow these steps:

1. Open the organization's general settings.
2. In the options menu, click `Export`.

The export page opens.

### Selecting the flows to export

To export the flows, follow these steps:

1. On the export page, select the flows you want to export. Include every flow in the same group.
2. At the bottom of the page, click the export button.

The platform generates a `.json` file. Use this file when you import the flows.

## Importing flows

Import uses the `.json` file from an export and adds the flows to an organization. You start the import from that organization's general settings.

To import the flows, follow these steps:

1. Open the general settings of the organization that will receive the flows.
2. In the options menu, click `Import`.
3. Select the `.json` file generated by the export.
4. Click `Import`.

The platform imports the flows into the organization.
