On the **Knowledge base** page of [Agent Builder](https://help.vtex.com/en/docs/tutorials/agent-builder-overview), you can add [files](#files), [websites](#websites), and [texts](#texts) to your agent's knowledge base. Agents will use the data from these documents to respond to users.

## Files

To add a file to the knowledge base, click <i class="fas fa-plus" aria-hidden="true"></i> `Add file`.

> ⚠️ Files must have a `.pdf`, `.doc`, `.docx`, `.txt`, `.xls`, or `.xlsx` extension and be up to 50 MB.

By clicking the <i class="fas fa-ellipsis-v" aria-hidden="true"></i> vertical ellipsis next to the file name, you can:

- Download the file.
- Remove the file from the knowledge base.

You can also use the search field to find a file in the knowledge base.

## Websites

To add a website to the agent's database, follow these instructions:

1. Click <i class="fas fa-plus" aria-hidden="true"></i> `Add website`.
2. Copy the URL of the website you want to add and paste it into the empty field.
3. Click `Done`.

By clicking the <i class="fas fa-ellipsis-v" aria-hidden="true"></i> vertical ellipsis next to the website, you can:

- Access the website.
- Remove the website from the knowledge base.

You can also use the search field to find a website in the knowledge base.

## Texts

On this tab, you can add text content to the knowledge base, organized into named segments. Each segment has its own title, and the list is ordered by most recent edit, showing when each segment was last modified.

To create a text segment, follow the steps below:

1. Click <i class="fas fa-plus" aria-hidden="true"></i> `Add text`.
2. Type a title to identify the segment.
3. Enter the content in the text box.
4. Click `Save`.

By clicking the <i class="fas fa-ellipsis-v" aria-hidden="true"></i> vertical ellipsis next to the segment, you can:

- Edit the content.
- Rename the title.
- Delete the segment. Deletion requires confirmation.

You can also use the search field to find a segment by title.

> ℹ️ Knowledge bases created before this organization keep the original text as a single segment, with a default title. No content is lost. The split into segments is only an interface change and doesn't affect how the agent uses the knowledge base content.
