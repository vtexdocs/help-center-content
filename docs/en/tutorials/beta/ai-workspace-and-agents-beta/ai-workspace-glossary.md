> ⚠️ AI Workspace is only available for selected accounts.

## A

### AI Workspace

Agentic operations platform for digital commerce management.

### Agent

Digital identities with well-defined skills, responsibilities, and scopes of action, which can act autonomously or on behalf of a user.

## C

### Canvas

Visual interface that supports [task](#task) [chats](#chat). The canvas displays and allows editing structured content related to ongoing work, such as tables, reports, dashboards, pages, campaigns, diagnoses, and action plans. It exists independently of a chat.

### Chat

Communication interface between users and agents. A chat allows users to request actions, approve decisions, and ask agents questions in natural language. Chats can be started by an [agent](#agent) when it creates an [initiative](#initiative) or starts a [task](#task), or by the user, through the message box or the performance indicators.

## I

### Initiative

A structure that organizes an action plan to achieve a business goal. Initiatives are proposed and created autonomously by [agents](#agent) when they identify problems, risks, or opportunities.

An initiative has the following characteristics:

- It has an [**initiative leader**](#initiative-leader), who is responsible for performing or coordinating the tasks required to achieve the expected result.
- It has [**participants**](#participant), who can be people or agents involved in the execution or follow-up.
- It has a severity level, which can be **Low**, **Medium**, or **High**. The severity is defined at creation, based on the estimated impact of the problem or opportunity.
- It can be in one of the following states: **Triage**, **Active**, **Archived**, or **Completed**.

### Initiative leader

The individual who receives all [initiatives](#initiative) related to a specific topic (for example, Catalog, Search, Promotions, Content). The leader's responsibilities are:

- Review initiatives
- Assign [tasks](#task) to an [assignee](#task-assignee)
- Perform tasks directly
- Approve the initiative results

## M

### Message

A unit of communication sent by a user or an [agent](#agent) in a [chat](#chat).

### My Assistant (agent)

The main AI assistant in VTEX [AI Workspace](#ai-workspace). It acts as the main conversational entry point for the merchant. My Assistant doesn't work directly on [tasks](#task); it creates and delegates plans.

### My assistant (page)

AI Workspace home page. This page displays the store's performance indicators, recommended initiatives, ongoing initiatives, and the message box to start a chat with an agent.

## P

### Participant

Users or [agents](#agent) involved in the execution or follow-up of an [initiative](#initiative).

## S

### Suggestion

A predefined prompt that helps the user start a new chat or continue an existing one.

## T

### Task

Goal-oriented action with defined scope, instructions, and success criteria. A task can be created by [agents](#agent), and its assignee can be a user or an agent. A task can be in the following states: **Open**, **Running**, **Awaiting action**, or **Completed**.

When an agent performs a task that requires review, approval, or a decision from the user, the agent opens a [chat](#chat) with the task result and requests the user's approval.

### Task assignee

The entity — human or [agent](#agent) — that performs the work in a [task](#task).
