> ℹ️ **Catalog Agent** is in closed beta and is only available to selected accounts. If you have any questions, contact [VTEX Support](https://help.vtex.com/en/docs/tutorials/opening-tickets-to-vtex-support).

**Catalog Agent** is an artificial intelligence agent in [AI Workspace](https://help.vtex.com/en/docs/tutorials/ai-workspace-overview) that helps catalog teams improve the content of several products at once. This allows you to correct text and add more complete information without editing each product separately in the VTEX Admin.

The agent is available in AI Workspace and is intended for content operators and catalog leads. You can receive suggestions in initiatives created by the agent or request changes through chat. In both cases, your team reviews the suggestions before any change is applied to the catalog.

## How Catalog Agent works

The agent suggests changes to four fields:

- **Product name:** Name displayed to customers on the product page and in other areas of the store.
- **Description:** Main text that presents the product's features and benefits.
- **SEO title:** Title that can appear as a link to the product page in search engines such as Google.
- **SEO meta description:** Summary that can appear below that link in search engine results.

SEO stands for search engine optimization and includes practices that help pages appear in search results.

Suggestions can follow your store's content guidelines, including writing rules, tone of voice, and restrictions. Because the text is generated by artificial intelligence, review each suggestion before approving it.

The agent doesn't create or delete catalog items and doesn't change data such as prices, stock, or images. The following table indicates where to perform these actions.

| Action | Where to perform it |
| :--- | :--- |
| Create or delete products, categories, and brands | VTEX Admin |
| Change prices or stock | VTEX Admin |
| Change images | Product or SKU registration in the VTEX Admin |

## Before you begin

Before working with Catalog Agent, check the following requirements:

- Your account must have access to the AI Workspace closed beta.
- To create or change content guidelines, your user must have the guidelines management permission. Without this permission, you can only view the guidelines.
- To request improvements based on your store's writing rules, create the content guidelines before starting the request.

To learn how initiatives, tasks, and chats work, see [AI Workspace - Initiatives](https://help.vtex.com/en/docs/tutorials/ai-workspace-initiatives), [AI Workspace - Tasks](https://help.vtex.com/en/docs/tutorials/ai-workspace-tasks), and [AI Workspace - Chat](https://help.vtex.com/en/docs/tutorials/ai-workspace-chat).

## Configuring content guidelines

Content guidelines are your store's writing rules. They're stored at the account level, shared by all users, and can include:

- **Content rules:** For example, use the "product name + brand" format in the title.
- **Tone of voice:** For example, use a friendly tone and short paragraphs.
- **Restrictions:** For example, never mention prices or promotions.

> ❗ Updating the guidelines replaces the previous version, which can't be recovered.

To create or update the guidelines, follow these steps:

1. In AI Workspace, go to the **My assistant** page.
2. In the **Message box**, use **Agent selection** to select **Catalog Agent**.
3. Send the rules the agent should follow.

    Example requests:

    - "Create the store's content guidelines based on this text:", followed by the rules.
    - "Update the content guidelines based on this text:", followed by the new rules.

4. Review the guidelines in the side panel, called the [canvas](https://help.vtex.com/en/docs/tutorials/ai-workspace-chat#canvas).
5. Confirm to save.

The confirmed guidelines apply to subsequent suggestions generated for all users in the account.

### Content guidelines example

The following example organizes the rules by field and includes general restrictions:

- **Product name:** Use the product type + brand + model + main feature format. Don't write entire words in uppercase.
- **Description:** Use a friendly tone and short paragraphs. Start with the main benefit and then list the features.
- **SEO title:** Use the product name + brand format.
- **SEO meta description:** Write one or two sentences that explain what the product is and who it's recommended for.
- **General restrictions:** Never mention prices, promotions, or delivery times. Don't use information that isn't in the product registration.

When writing the guidelines:

- Organize rules by field.
- Define the format, information order, and prohibited terms.
- Record restrictions explicitly.
- Keep a copy outside AI Workspace because there's no version history.

## Catalog Agent initiatives

In AI Workspace, an initiative groups tasks created to correct a problem identified by the agent. Catalog Agent creates initiatives when it finds the following problems:

- Weak SEO title
- Weak SEO meta description
- Low-quality product name
- Low-quality description

To identify these problems, the agent considers criteria such as clarity, amount of information, specificity, and consistency with the registered product data.

To build an initiative, the agent analyzes in-stock products responsible for most of the store's recent revenue. It then prioritizes the highest-revenue products among those with the identified problem. Each initiative includes up to 20 products.

Each task covers a single field and presents suggestions for the products in the initiative. When a task is awaiting your action, open the review and follow the instructions in [Reviewing and applying suggestions](#reviewing-and-applying-suggestions).

## Requesting changes through chat

Through chat, you send a product list, specify the fields you want to change, and select one of the following ways to generate suggestions:

- **Specific correction:** Describe exactly what you want to change.
- **Guideline-based improvement:** Specify the fields so that the agent suggests text according to your store's rules.

To request changes, follow these steps:

1. In AI Workspace, go to the **My assistant** page.
2. In the **Message box**, use **Agent selection** to select **Catalog Agent**.
3. Send the product list, the fields, and, for a specific correction, the desired change.

    If you don't specify the fields, the agent asks whether you want to change the product name, description, SEO title, or SEO meta description. No suggestions are generated before you respond.

4. Review the suggestions displayed in the canvas.

> ℹ️ The requests below are illustrative examples. You can write the instructions in other ways.

In the examples, the ID is the numeric code that identifies the product in the catalog.

| Method | Example request | Expected result |
| :--- | :--- | :--- |
| Specific correction | "Remove the term 'New' from the names of products with IDs 1021, 1022, and 1035." | The agent presents a name suggestion without the term for each product. |
| Guideline-based improvement | "Improve the SEO title and SEO meta description of products with IDs 2040, 2041, 2042, and 2043." | The agent presents suggestions for both fields of each product according to the guidelines. |

The agent doesn't generate a suggestion when the text already follows the guidelines or doesn't need the requested correction. If no field needs a change, the agent reports the result in the chat.

When a suggestion conflicts with the guidelines, the agent reports the conflict. In this case, update the guidelines or confirm that you want to apply the change anyway.

## Reviewing and applying suggestions

The review canvas shows the **Current** value and the **Suggestion** for each field. Every suggestion starts as pending, and no change is applied to the catalog without your approval. The same review is used for initiative tasks and requests made through chat.

### Approving suggestions

You can approve all pending suggestions or only a selection:

- **All pending suggestions:** Click `Approve all`. The button shows how many suggestions will be approved.
- **A selection:** Select the desired suggestions and click `Approve` in the selection bar. The action only affects the selected suggestions.

Before applying the changes, a confirmation states how many suggestions will be applied to the catalog and how many will remain pending.

After confirmation, the field shows **Applying...** and the `Undo` option. While this option is available, click `Undo` to return the suggestion to the pending state without changing the catalog. After you click `Approve all`, a single `Undo` action reverts all approvals from that action.

When the change is applied to the catalog, the field shows **Approved**. If the change fails, the field shows **Error** and keeps the current value. Click `Try again` to repeat the action. A failure in one field doesn't prevent the other approved suggestions from being applied.

### Ignoring suggestions

To ignore several suggestions, select them and click `Ignore` in the selection bar. To ignore one suggestion, click `Ignore` in its actions menu.

An ignored suggestion doesn't change the catalog. The field shows **Ignored** and the `Undo` option, which is available until the task is finished.

### Requesting an adjustment or explanation

For each suggestion, you can:

- **Request an adjustment:** Click `Adjust`, describe the change, and send it. The agent generates a new version, which replaces the previous one and remains pending. For example: "Make the title shorter and keep the brand at the beginning."
- **Request an explanation:** In the actions menu, click `Explain`. The agent explains in the chat why it made the suggestion. For example: "Why did you suggest this title for product ID 1021?"

### Finishing the task

When all suggestions are approved, the task finishes automatically. If all suggestions have been reviewed and at least one has been ignored, AI Workspace asks you to confirm that you want to finish the task. You can also finish the task while there are pending suggestions.

> ❗ Finishing a task can't be undone. Pending suggestions are recorded as ignored and don't change the catalog.

To finish the task manually:

1. In the review canvas, click `Finish`.
2. Check which suggestions won't be applied.
3. Confirm that you want to finish the task.

After the task is finished, the canvas shows **Task completed** and becomes read-only. Approved suggestions remain applied, while ignored and unreviewed suggestions keep the field's current value. The chat remains available for questions, such as requesting a list of changed products.

## Closed beta limitations

During the closed beta:

- The agent only changes the product name, description, SEO title, and SEO meta description.
- Each request accepts a limited number of products. If the list exceeds this limit, the agent doesn't process the request. Split the products into smaller lists and send one request for each list.
- After the products and fields for a task are defined, you can't add other items. Start a new chat to work with other products or fields.
- Guidelines can only be created and updated through chat. You can't upload a file or recover previous versions.
- The agent doesn't guarantee exact wording. Review the suggestions and request adjustments when necessary.

## Frequently asked questions

### Why wasn't my product included?

In initiatives, the product might not meet the stock, revenue, or prioritization criteria. Each initiative includes up to 20 products. For requests made through chat, the product doesn't appear in the review when none of the requested fields needs a change.

### Why didn't the agent suggest a change for a field?

The agent doesn't generate suggestions when the text already follows the guidelines or doesn't need the requested correction. The agent also doesn't change fields other than the product name, description, SEO title, and SEO meta description.

### Why wasn't my request processed?

The list might have exceeded the product limit, or the agent might not perform the requested action. For long lists, split the products into smaller groups. To create products or change prices, stock, and images, use the VTEX Admin.

### Can I add products to a completed task?

No. To work with other products or fields, start a new chat.
