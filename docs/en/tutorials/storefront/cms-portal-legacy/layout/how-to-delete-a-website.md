> ⚠️ Tutorial valid only for Legacy CMS Stores.

> ❗ Be very careful with this action. If you delete one of your websites, all the files and folders on this website will be deleted permanently. You will not be able to retrieve them. You can't delete the **default website**.

To delete a website, follow the steps below:

1. In the VTEX Admin, go to **Storefront > Layout**.
2. Click the **CMS** folder.
3. Click the **Sites and Channels** folder.
4. Click **Delete** on the line corresponding to the website you want to delete.
5. Confirm that this is the website you want to delete. If so, type `yes` in the text box and click the **Delete** button.
