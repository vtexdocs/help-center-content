We launched bulk sending of quick messages in [Live Desk](https://help.vtex.com/en/docs/tutorials/visao-geral-do-live-desk), which lets representatives send a saved quick message to multiple conversations at once, directly from the message's options menu. This feature is in general availability for VTEX stores in all regions.

## What has changed?

Previously, to send the same quick message to multiple contacts, representatives had to open each conversation and send it one by one, which slowed down communication during high-volume periods and made it harder to standardize messages.

Now, from the options menu of a saved quick message, representatives can:

- Send to multiple conversations at the same time, without opening each one.
- Choose the contacts who will receive the message. By default, all contacts come selected.
- Review before sending, through a confirmation checklist that prevents accidental bulk sends.
- Track the send with a real-time progress bar and receive a confirmation notification with the number of conversations that received the message.

Bulk sending also works with quick messages. You can use it with any quick message already added, without creating a new template. To do this, open the message's options menu and select Send in bulk. For more information, see [Live Desk overview](https://help.vtex.com/en/docs/tutorials/visao-geral-do-live-desk).

## What needs to be done?

No action is required. The feature is already available to all VTEX CX Platform users with quick messages added.

To learn how to add quick messages, go to [Configuring Live Desk](https://help.vtex.com/en/docs/tutorials/configurar-o-live-desk#setores).

For more information, go to [Live Desk overview](https://help.vtex.com/en/docs/tutorials/visao-geral-do-live-desk).
