Rediseñamos la página de configuración de pedidos y checkout en el Admin VTEX. La configuración ahora está disponible en una nueva experiencia independiente, con una interfaz más moderna y una carga más rápida, manteniendo los mismos ajustes actuales.

El acceso a la página sigue requiriendo los recursos de [License Manager](https://help.vtex.com/es/announcements/2025-10-21-nuevos-recursos-de-license-manager-configuracion-pedidos) `Save Order Configuration` y `Save OrderForm Configuration`.

## ¿Por qué realizamos este cambio?

Las principales ventajas de este cambio son:

- Interfaz más moderna y responsiva para gestionar la configuración de pedidos y checkout.
- Carga más rápida y mayor estabilidad, ya que la página ahora funciona como una aplicación independiente.
- Una experiencia más consistente, alineada con la evolución del Admin VTEX.

## ¿Qué se necesita hacer?

A partir del 22 de julio, la versión beta de la página de configuración estará disponible para algunas tiendas VTEX seleccionadas. Esta experiencia se activará gradualmente en las próximas semanas. Tu configuración existente se conservará. Durante el periodo de validación, si deseas volver a la versión anterior de la página de configuración, puedes hacer clic en el botón `Volver a la versión anterior`.

A partir del 1 de septiembre, la nueva interfaz de configuración de pedidos será la opción predeterminada para todas las tiendas VTEX.
