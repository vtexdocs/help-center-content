[PCI Security Standards Council (PCI SSC)](https://www.pcisecuritystandards.org/es/) es un foro global abierto que desarrolla, mejora, almacena, divulga e implementa estándares de seguridad para la protección de datos. El consejo fue fundado por las empresas American Express, Discover Financial Services, JCB International, Mastercard y Visa Inc.

Entre los estándares que mantiene PCI SSC se encuentra el [Estándar de Seguridad de Datos (PCI DSS)](https://www.pcisecuritystandards.org/es/standards/pci-dss/), que define los requisitos de seguridad para las empresas que procesan, almacenan o transmiten datos de tarjetas de crédito y débito. VTEX está certificada en PCI DSS como proveedora de servicios. Los datos de tarjeta que los clientes ingresan en el entorno de VTEX se tratan en una infraestructura certificada, así que tu tienda no necesita una certificación PCI propia para vender en ese entorno. La excepción son las aplicaciones móviles nativas, que envían los datos de pago a VTEX desde un entorno externo, como se explica en el artículo [¿Es necesario tener certificado PCI para vender en apps móviles nativas?](/es/docs/tutorials/es-necesario-tener-certificado-pci-para-vender-en-apps-moviles-nativas).

El certificado PCI DSS de VTEX está disponible en [VTEX Trust Center](https://compliance.vtex.com/?itemUid=53e1508c-665e-45a8-9ce0-03fdf9ae1efb&source=title).
