**Desk Copilot** ayuda a los representantes humanos en [Live Desk](https://help.vtex.com/es/docs/tutorials/informacion-general-de-live-desk) a responder a los clientes con más rapidez. Lee la conversación activa, reacciona a cada mensaje del cliente y sugiere la siguiente mejor acción. El representante humano mantiene el control: decide si copia, edita o envía cada sugerencia.

## Cómo funciona Desk Copilot

**Desk Copilot** funciona como un proyecto independiente, dentro de la misma organización que tu proyecto de atención de **VTEX CX Platform**. Este proyecto cuenta con los siguientes componentes:

- **Manager:** agente configurado para coordinar las sugerencias y apoyar a los representantes humanos.
- **Base de conocimiento interna:** reúne información de uso exclusivo del equipo de soporte, que no debe compartirse directamente con los clientes.
- **Agentes comerciales oficiales:** los mismos agentes utilizados por los agentes de IA para acceder a funcionalidades comerciales.

Para generar sugerencias, **Desk Copilot** analiza el contexto de la conversación, incluyendo mensajes de texto, audios transcritos y archivos compartidos por el cliente, como PDFs.

También puedes utilizar [agentes personalizados](https://help.vtex.com/es/docs/tutorials/asignar-y-probar-agentes#asignar-un-agente-al-equipo) en Desk Copilot para extender sus funcionalidades. Para saber cómo activar y configurar Copilot, consulta [Uso de Desk Copilot para apoyar a los agentes en Live Desk](https://help.vtex.com/es/docs/tutorials/uso-de-desk-copilot-para-apoyar-a-los-agentes-en-live-desk).

## Tipos de sugerencia

En cada mensaje del cliente, Desk Copilot puede proponer una de las siguientes acciones:

- Respuestas: mensajes listos para enviar, con un tono adecuado para la atención.

- Búsqueda de productos: resultados de búsquedas conversacionales presentados en carruseles.

- Carritos: carritos con productos mencionados en la conversación.

- Consultas de pedidos: acciones para consultar información de pedidos.

- Enlaces de pago: sugerencias de enlaces para facilitar la finalización de compras.

Para saber cómo usar y evaluar las sugerencias en Live Desk, consulta [Uso de Desk Copilot para apoyar a los agentes en Live Desk](https://help.vtex.com/es/docs/tutorials/uso-de-desk-copilot-para-apoyar-a-los-agentes-en-live-desk).

## Activar Desk Copilot

1. En el proyecto deseado de VTEX CX Platform, haz clic en **Configuración > Live Desk**.
2. Selecciona la pestaña **Desk Copilot**.
3. Haz clic en `Crear proyecto Copilot`.
4. Define el nombre del proyecto.

    > ⚠️ De forma predeterminada, el nombre sugerido es el mismo que el del proyecto de atención. Para facilitar su identificación, recomendamos utilizar un nombre diferente o agregar **Copilot** al nombre original. Por ejemplo: **Proyecto X Copilot**.

5. Haz clic en `Crear`.

Después de crear el proyecto Desk Copilot, serás redirigido a la página **Analytics**.

## Facturación

Las conversaciones asistidas por Desk Copilot se facturan como conversaciones regulares de VTEX CX Platform. No es necesario cambiar tu contrato para usar esta funcionalidad.
