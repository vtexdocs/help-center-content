En la página de la **Base de conocimiento** de [Agent Builder](https://help.vtex.com/es/docs/tutorials/informacion-general-de-agent-builder), puedes agregar [archivos](#archivos), [sitios web](#sitios-web) y [textos](#textos) a la base de conocimiento de tu agente. Los agentes utilizarán los datos de estos documentos para responder a los usuarios.

## Archivos

Para agregar un archivo a la base de conocimiento, haz clic en <i class="fas fa-plus" aria-hidden="true"></i> `Agregar archivo`.

> ⚠️ Los archivos deben tener extensión `.pdf`, `.doc`, `.docx`, `.txt`, `.xls` o `.xlsx` y un tamaño de hasta 50 MB.

Haciendo clic en los <i class="fas fa-ellipsis-v" aria-hidden="true"></i>tres puntos junto al nombre del archivo, puedes:

- Descargar el archivo.
- Remover el archivo de la base de conocimiento.

También puedes usar el campo de búsqueda para encontrar un archivo en la base de conocimiento.

## Sitios web

Para agregar un sitio web a la base de datos del agente, sigue los pasos a continuación:

1. Haz clic en <i class="fas fa-plus" aria-hidden="true"></i> `Agregar sitio web`.
2. Luego, copia la URL del sitio web que deseas agregar y pégala en el campo vacío.
3. Haz clic en `Finalizar`.

Haciendo clic en los <i class="fas fa-ellipsis-v" aria-hidden="true"></i>tres puntos junto al sitio web, puedes:

- Acceder al sitio web.
- Remover el sitio web de la base de conocimiento.

También puedes usar el campo de búsqueda para encontrar un sitio web en la base de conocimiento.

## Textos

En esta pestaña, puedes agregar contenido de texto a la base de conocimiento, organizado en segmentos nombrados. Cada segmento tiene su propio título, y la lista se ordena por la edición más reciente, con la indicación de cuándo se modificó cada segmento.

Para crear un segmento de texto, sigue los pasos a continuación:

1. Haz clic en <i class="fas fa-plus" aria-hidden="true"></i> `Agregar texto`.
2. Escribe un título para identificar el segmento.
3. Ingresa el contenido en el cuadro de texto.
4. Haz clic en `Guardar`.

Haciendo clic en los <i class="fas fa-ellipsis-v" aria-hidden="true"></i>tres puntos junto al segmento, puedes:

- Editar el contenido.
- Cambiar el título.
- Eliminar el segmento. La eliminación requiere confirmación.

También puedes usar el campo de búsqueda para encontrar un segmento por título.

> ℹ️ Las bases de conocimiento creadas antes de esta organización mantienen el texto original como un único segmento, con un título predeterminado. No se pierde ningún contenido. La división en segmentos es solo un cambio de interfaz y no altera la forma en que el agente usa el contenido de la base.
