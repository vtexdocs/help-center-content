Este template envía la segunda vía en PDF, el extracto en PDF y el saldo deudor, y realiza cobros por canales externos, como WhatsApp. El template se desarrolló en VTEX CX Platform y usa la plataforma Sienge.

## Antes de comenzar

Para el funcionamiento completo de la automatización, crea un usuario de API con permiso para consumir los recursos de abajo:

- Generación de boleto (Segunda vía)
- Generación del saldo deudor presente del cliente
- Títulos de cuentas por cobrar
- Extracto de cliente por correo electrónico
- Clientes
- Gestión de webhooks
- Historial de notificación de cobro
- Contratos de ventas
- Saldo deudor presente del cliente (Total)
- Centro de costos

Para crear un usuario de API, sigue este [paso a paso](https://www.youtube.com/watch?v=w0f9O20ZeLM&list=PLel5qygu4y7SE1xF8UmVhJBJX6S5YavCE).

Para ver cómo funciona el template, mira la [demostración](https://www.youtube.com/watch?v=Z7KYanhT-aw&feature=youtu.be).

Para usar este template, contacta al equipo comercial de VTEX y solicita una demostración.
