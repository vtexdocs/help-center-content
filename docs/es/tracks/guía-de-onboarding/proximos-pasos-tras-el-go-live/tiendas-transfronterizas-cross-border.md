Una tienda internacional, también llamada cross-border, es un tipo de [multitienda](https://help.vtex.com/es/docs/tutorials/gestionar-multitienda). En VTEX, esto se traduce en una cuenta con múltiples [bindings](https://help.vtex.com/es/docs/tutorials/que-es-binding) y diferentes canales de venta para cada una de tus tiendas locales.

Las tiendas internacionales pueden alcanzar compradores en todo el mundo al ofrecer experiencias de compra localizadas para los clientes de cada región.

Si deseas ofrecer esta experiencia de compra localizada a tus clientes, abre un ticket con el [Soporte VTEX](https://support.vtex.com/) indicando tu interés en convertirte en una tienda internacional.

Una tienda internacional te ayuda a:

- Impulsar el crecimiento de tu negocio al vender productos en mercados globales.
- Crear una reputación internacional de la marca.
- Ofrecer medios de pago locales o confiables en cada mercado.
- Gestionar todas las tiendas locales en el mismo entorno VTEX.

## Conceptos esenciales

Al configurar una tienda internacional en la plataforma VTEX es importante entender algunos conceptos: [multitienda](#multiloja), [binding](#binding) y [política comercial](#politica-comercial).

### Multitienda

Una multitienda, también llamada subcuenta o multidominio, es una segunda tienda administrada dentro del mismo panel del Admin VTEX. Esta funcionalidad suele utilizarse cuando la tienda tiene varias marcas con logística y medios de pago similares, o cuando la operación requiere entornos específicos (por ejemplo, soporte para ventas B2B).

> ℹ️ Consulta [Gestionar multitienda](https://help.vtex.com/es/docs/tutorials/gestionar-multitienda).

### Binding

El binding es el proceso de vincular un sitio web a una de las tiendas disponibles en tu cuenta. La creación de un binding es uno de los pasos para configurar un sitio web personalizado para un país específico u otro público objetivo.

> ℹ️ Consulta [¿Qué es binding?](https://help.vtex.com/es/docs/tutorials/que-es-binding).

### Política comercial

Una política comercial define los contenidos que se van a mostrar en el sitio web. Las políticas comerciales contienen configuraciones relacionadas con catálogo, precios, promociones, logística, segmentación de clientes y pagos para diversas estrategias de venta.

> ℹ️ Consulta [Cómo funciona una política comercial](https://help.vtex.com/es/docs/tutorials/como-funciona-una-politica-comercial).

## Tiendas multilingüe

Como una tienda internacional puede tener múltiples bindings y alcanzar compradores en todo el mundo, es importante ofrecer la internacionalización del contenido del sitio web y del catálogo para que los consumidores tengan una experiencia de compra personalizada.

Para internacionalizar el contenido de tu tienda ponte en contacto con tu equipo de desarrolladores y consulta la documentación sobre [Internacionalización](https://developers.vtex.com/docs/guides/vtex-io-multi-language-stores) y [Traducción de contenido del catálogo](https://developers.vtex.com/docs/guides/catalog-internationalization).
