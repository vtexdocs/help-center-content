Este artículo describe los requisitos técnicos para utilizar **VTEX Sales App**.

> ℹ️ Algunas funcionalidades específicas de **Sales App** pueden exigir otros requisitos técnicos. Este artículo está orientado al uso básico de **Sales App**.

## Equipo obligatorio

La tienda necesita un dispositivo para utilizar **Sales App**, ya sea una computadora de escritorio o un dispositivo móvil, como tablet, smartphone o tótems digitales táctiles.

> ⚠️ Te recomendamos reservar un espacio seguro en tu tienda para almacenar el equipo.

### Tablets, smartphones y tótems digitales táctiles

Preferentemente, el dispositivo debe estar actualizado con la versión más reciente del sistema operativo y, como mínimo, ser compatible con:

- Las tres versiones más recientes de **iOS**
- Las cuatro versiones más recientes de **Android**

El dispositivo debe tener conexión a internet, ya sea por Wi-Fi o 4G/5G. Lo ideal es que el dispositivo móvil tenga chip 4G/5G para que la tienda siga funcionando con normalidad aunque la red Wi-Fi presente algún problema.

> ℹ️ Para mantener el buen funcionamiento de la operación recomendamos tener más dispositivos que vendedores. De este modo, los dispositivos se pueden reemplazar rápidamente en caso de falla, daño o agotamiento de la batería.

### Computadoras

Para usar **Sales App** en una computadora el dispositivo debe cumplir con los siguientes requisitos:

- **Windows:**
  - Sistema operativo **Windows 10** o posterior.
  - Memoria RAM de **4 GB** o superior.

- **macOS:**
  - Sistema operativo **macOS 13 Ventura** o posterior.
  - Memoria RAM de **4 GB** o superior.

### Router e internet

La conexión a internet es fundamental para usar **Sales App**. Los requisitos mínimos y las recomendaciones adicionales son:

| Equipo   | Requisitos mínimos                                                                                                                                                        | Recomendaciones adicionales                                                                                                                                                                                     |
| :------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Router   | Frecuencia predeterminada de 2.4 GHz (802.11n) y conexión de 20 Mbps entre el dispositivo y el router. | Frecuencia predeterminada de 5 GHz (802.11ac) y conexión de 40 Mbps entre el dispositivo y el router. El smartphone debe ser de doble banda. |
| Internet | Velocidad del link de 2 Mbps en el dispositivo (resultado de la prueba de velocidad en el smartphone).                                 | Velocidad del link de 5 Mbps en el dispositivo (resultado de la prueba de velocidad en el smartphone).                                                                       |

## Equipo opcional

Aunque no son obligatorios, recomendamos los siguientes equipos para obtener la mejor experiencia con **Sales App**.

### Lector de código de barras

**Sales App** tiene un lector de código de barras nativo que funciona a través de la cámara de los smartphones y permite leer los códigos de barras de los productos. Sin embargo, un dispositivo exclusivo para esta función tiene un desempeño superior.

Para agilizar las compras recomendamos que la tienda cuente con un lector de código de barras, especialmente cuando se usa una computadora de escritorio.

> ℹ️ Para usar el lector de código de barras, registra el código de barras del producto en Catálogo, como se describe en [Registrar el código de barras de los SKUs para VTEX Sales App](https://help.vtex.com/es/docs/tracks/registrar-el-codigo-de-barras-de-los-skus-para-vtex-sales-app).

### Terminales de pago

Las terminales de pago para tarjetas de crédito y débito, con tecnología Bluetooth o USB, permiten que las tiendas físicas procesen pagos. Las ofrecen partners de pago, ya sean adquirentes o subadquirentes.
